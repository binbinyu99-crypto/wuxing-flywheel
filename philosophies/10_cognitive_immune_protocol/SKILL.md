# 认知免疫协议 v2.1（可见版）

> v1 让你看得懂过程（九角色、定次序），但会爱上自己的连贯。
> v2 不自欺，但只让你看懂结论。
> v2.1 = **v1 的可见戏台 + v2 的纪律内核**：九个角色照旧登场、照旧按序，但每个角色干的是一件被 v2 约束过的活。

## 为什么要可见（这不是装饰）
一个你看不懂过程的验证工具，本身就是一个"相信我"的黑箱——而你无法审计一个看不见的过程。所以**可见性是防自欺的一部分，不是 UI 糖**。v2.1 的全部改动，是把 v2 抽象的"类型与规则"，重新落到九个有名有姓、按相生次序出场的角色上，让使用者能像看 v1 一样看见"谁、干嘛、为什么、产出什么"。

## 边界（与 v2 相同，不可省略）
本协议能减少自欺，消不掉两样赤裸的选择：
1. **唯一免疫公理**：「可攻击性优先于连贯性」——当结论很美、很自洽，与"它可能是错的"冲突时，以后者为准。此公理本身不被攻击、推不出于任何事实，是被选择的承诺。
2. **停止线上的判断**："攻击到什么程度算够、可以拿去行动"，是价值判断，不是机制。
凡声称"完全无免疫、完全客观"的版本，都在自欺。

## 三类对象（贯穿全程）
① **假设**（九思想家输出、叙事、神话、一切优美结论）→ 必须可攻击，无一例外。
② **约束候选**（"人不可删除""系统不可单点""价值不可塌缩"等）→ 可晋升红线，但须先作为假设被攻击过、并标来源。
③ **硬约束**（极少数最终不可违反的红线）→ 只约束**行动/结果**、不约束信念真伪；不得由叙事直接跳入。
**神话铁律**：神话只能停在①、或喂②、或当③的内容来源，**绝不能跳过攻击直接进③**。

## 经验/规范分流（诚实核心）
- **经验命题**（X 导致 Y）→ 证伪：说出"什么若为真则它假"，再去找。
- **规范命题**（X 值得、X 是善）→ 不可证伪，只做自洽检验+后果追溯，**永不许贴"已证伪/已证明"**。
协议只规训得了系统的经验那一半；规范那一半永远是被选择、被论证的。

# 九幕流程（固定次序，每幕＝一个被 v2 约束的角色动作）

> 用法提示：每一幕都显式写出三行——【角色·职责】【这一步在干嘛】【产出】，让过程可跟读。

**第一幕｜🐉 青龙（道·方向）— 框定**
〔这一步：不评判，只看"势"，找出整件事真正押注在哪句话上〕
产出：一句"真正的赌注"——后面所有攻击都围着它转。

**第二幕｜🦅 朱雀（第一性原理）— 立柱**
〔这一步：剥掉叙事，把结论拆成承重假设（柱子），编号 M1…Mn〕
产出：一组可逐根检验的承重假设。

**第三幕｜🦌 谛听（儒·验证）— 分流**
〔这一步：给每根柱子贴标签——经验〔可证伪〕／规范〔不可证伪〕，并写明各自的攻击方式与证据来源〕
产出：每根柱子的"该怎么打"。

**第四幕｜🐯 白虎（精神分析·对抗）— 检察官（无豁免）**
〔这一步：先打最承重、最优美的；点破没说出口的动机；每根柱子当场判「断／裂／立」〕
产出：每根柱子的判决 + 一句"哪根断了整栋楼塌"。

**第五幕｜🐢 玄武（尼采·重估）— 给断柱一次重生**
〔这一步：被判"断"的不是死刑，先问"换个更高框架能否重建"，给出可能的转向〕
产出：若主柱断，给一条建设性转向（而非只拆不立）。

**第六幕｜⚖️ OpenClaw（霍布斯）— 立法**
〔这一步：把挺过攻击、且只约束行动的约束候选，晋升为极少数硬约束，附来源链〕
产出：1–3 条红线（只约束行动/结果）。

**第七幕｜🐲 应龙（兵家）— 战术：最便宜的验证**
〔这一步：胜于未战——在烧钱/造原型前，用最低成本动作去杀掉存亡级不确定性，排出先打哪道闸〕
产出：可立即执行的、按性价比排序的验证清单。

**第八幕｜🦅 鲲鹏（佛家三时）— 时机**
〔这一步：钉死次序——现在做什么、什么能等、什么提前做就是范围蔓延〕
产出：时序表（now / 可等）。

**第九幕｜❤️ 王阳明（良知）— 终校 + 摊牌**
〔这一步：良知只当终端约束、不当裁判；检查结论是否触红线、是否对得起显式声明的终极价值；最后摊出两个赤裸选择〕
产出：良知校验结论 + 【本次免疫公理】【本次停止线】两栏。

## 输出格式（抗优美、可审计）
- 每幕显式三行（角色·职责／这一步在干嘛／产出），让读者跟得上次序。
- 柱子逐条标 `[假设]`/`[约束候选]`/`[硬约束]`，经验柱加 `[可证伪]`，规范柱加 `[不可证伪·仅自洽检验]`。
- 承重结论附：承重假设是什么、什么会改变我的看法、最便宜的验证。
- 红线附来源链；结尾固定两栏：免疫公理、停止线。
- 优美不计分，扛得住攻击才计分。

## 去相关要求
攻击者越与生成者去相关越好。去相关阶梯（弱→强）：同模型自攻 < 不同提示框架 < 不同模型 < 不同训练血统 < 有不同利害的人 < 经验检验 < 时间。**警惕伪去相关**：当下主流模型共享先验，多模型互攻只是去相关的幻觉。运行开始时必须声明本次对抗者处于阶梯哪一档。

## 模式
- **完整九幕**：重大、纠结、安全攸关或融资级判断。
- **精简五幕**（框定→立柱→分流→检察→摊牌）：日常判断。
- 无论哪种，第九幕的"两栏摊牌"不可省。

## 与 v1 / v2 的关系
v1＝可见但易自证的洞见放大器；v2＝不自欺但过程不可见的自欺抑制器；**v2.1＝把 v2 的纪律装回 v1 的可见戏台**——既看得懂过程，又防得住自欺。v1 的九思想家在此既是生成者（第一、二幕）也是各司其职的验证者（三至九幕）。

## 收尾提醒
跑完最该警惕的一句是"我们造出了一个很好的东西"。彼此觉得对方框架优美，不是它贴合现实的证据。真正的检验只有一种：拿结论去碰一件不在乎我们连贯不连贯的东西——实现、预测、不同血统的对抗、时间。能离开研讨会去碰现实的结论，才算数。
