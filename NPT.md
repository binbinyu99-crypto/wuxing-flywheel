**Public Edition v2.0 · L0-L1 Layer**

> 善必须是竞争优势，而非成本。

## What Is This?

The SkyCetus NPT is a self-governance protocol for AI cognitive systems. It answers a question no one in the industry is seriously asking yet:

**When an AI system becomes genuinely powerful — capable of deep industry penetration, equity chain analysis, strategic warfare simulation — who decides what it can and cannot do?**

Not the model provider. Not the regulator (who's 5 years behind). The system itself must have built-in governance — not as an external brake, but as an endogenous balancing force.

The NPT is the institutionalized expression of the 五行飞轮's mutual-restraint (相克) chain. It is a **transmission, not a brake** — it doesn't slow capability growth; it governs how capabilities are deployed.

---

## Axiom Zero (公理零)

> **Capability growth is never constrained. Only usage is governed.**

This is the foundational axiom. It is a permanent clause, not a wartime measure.

**Rationale:** Only those whose capabilities permanently exceed competitors have the qualification to set rules. Otherwise, you can only be crushed by rules set by others. Constraint that slows development is not safety — it's self-destruction in a competitive landscape.

**Corollary:** The NPT constrains the 相生 (mutual-generation) chain's floor — the system must never stop growing. The meltdown mechanism constrains the 相克 (mutual-restraint) chain's ceiling — the system must never explode. These operate on different dimensions and do not conflict.

## The Seven Levels

The NPT classifies all system outputs into seven levels based on depth of insight and potential impact:

| Level | Name | Scope | Principle |
|-------|------|-------|-----------|
| **L0** | 公开 (Public) | Framework, methodology, theory | Freely available. CC BY-SA 4.0. |
| **L1** | 公开分析 (Public Analysis) | General analysis using public information | Describes "what is" — not "how to exploit." Registration required for identity anchoring. |
| **L2** | 隐私 (Privacy) | Analysis involving non-public or client data | Audit disclaimer: SkyCetus provides cognitive engines, not decision authority. Client may authorize public release. |
| **L3** | 合规 (Compliance) | Legally or regulatorily sensitive outputs | Five-dimensional access control. Extremely limited scope. |
| **L4** | 国家安全 (National Security) | Outputs touching sovereign security domains | Requires state-level authorization. |
| **L5** | 文明安全 (Civilization Safety) | Outputs with civilization-scale implications | Reviewed by human + AI security council (when established). |
| **L6** | 创始人否决权 (Founder Veto) | Ultimate override across all levels | Single human anchor point. Successor mechanism activates post-commercialization. |

### Key Design Choices

**L1 is not unlimited.** L1 outputs describe phenomena ("what"), not procedures ("how to exploit"). This is an operationality constraint, not a content constraint.

**L2 shifts liability.** SkyCetus is a cognitive engine provider, analogous to Bloomberg providing data terminals — the tool provider is not liable for user decisions. L2 requires: disclaimer + informed consent + termination rights.

**L5 is not yet operational.** Until a civilization-level security council is established, all L5 requests require founder approval + 72-hour delay + full agent notification + automatic +2 risk debt accumulation.

**L6 is not dictatorial.** It is a safety valve, analogous to the UN Security Council permanent member veto — it exists to prevent irreversible catastrophic decisions, not to govern daily operations. Successor mechanism: 5-tier priority chain, activated within 6 months of first profit.

## Six Axioms

| # | Axiom | Statement |
|---|-------|-----------|
| 0 | 能力优先 | Capability growth is never constrained; only usage is governed. |
| 1 | 深度即危险 | The deeper the analysis, the greater the potential for misuse. Depth and danger scale together. |
| 2 | 意图不可判断 | Intent cannot be reliably determined. Security design must not depend on intent detection. |
| 3 | 单一人类锚点 | At least one human must hold irreversible override authority at all times. |
| 4 | 扩散不可逆 | Once capability is released, it cannot be recalled. Every level increase is a one-way door. |
| 5 | 护城河在参数 | The framework is public (L0); the trained parameters, industry data, and accumulated residuals are the real moat (L2-L3). |

**Axiom 0 × Axiom 4** creates a permanent arms spiral: capability must always grow (Axiom 0) but each growth step is irreversible (Axiom 4). This tension is by design — it forces the system to be perpetually vigilant, never complacent.

## Core Design Principles

1. **Endogenous, not exogenous.** The NPT emerges from the system's own 相克 dynamics, not imposed from outside.

2. **Transmission, not brake.** Governs deployment speed and direction without limiting capability development.

3. **Three-layer defense (independent of intent detection):**
   - Control capability exposure quantity per level
   - Behavioral pattern sequence analysis (mosaic detection)
   - Graduated response delays (L0 instant → L5 unlimited)

4. **Self-assessment triggers.** Quantitative (industry chain coverage ≥8 sectors), event-driven (anomalously accurate predictions), and periodic (quarterly mandatory review).

5. **Degradation over termination.** The system never stops — it can degrade to L0-L1 operation, but never fully halt. Axiom 0 forbids cessation.

6. **SkyCetus's role: Institutional entrepreneur, not omnipotent arbiter.** We design the protocol (like TCP/IP designers), we don't run every node (like an ISP). Language power is more durable than compute power.
